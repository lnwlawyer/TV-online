# Online TV TH v0.1

เว็บแอปดูทีวีออนไลน์ส่วนตัว (React + Vite + HLS.js) ภาษาไทย ธีมมืด รองรับมือถือและคอมพิวเตอร์

## เริ่มใช้งานบน Windows 11
1. ติดตั้ง Node.js LTS จาก https://nodejs.org/
2. แตก ZIP และดับเบิลคลิก `START-WINDOWS.bat`
3. เปิด `http://localhost:5173/` หากเบราว์เซอร์ไม่เปิดเอง
4. คลิก **จัดการช่องทีวี** เพื่อเพิ่ม URL สตรีมหรือนำเข้าไฟล์ `.m3u`

## ทดลองไฟล์ M3U
ไฟล์ `example-playlist.m3u` เป็นเพียงแม่แบบ ไม่มีสตรีมจริง ให้แทนที่ URL ด้วยสตรีมที่คุณมีสิทธิรับชม

## เผยแพร่บน GitHub Pages
1. สร้าง GitHub repository ใหม่ และอัปโหลดไฟล์ทั้งหมดรวม `.github/workflows/deploy.yml`
2. ใช้ branch `main` โดยคงโครงสร้างโฟลเดอร์ทั้งหมด
3. ไปที่ **Settings → Pages → Build and deployment → Source: GitHub Actions**
4. เปิดแท็บ Actions รอ workflow `Deploy GitHub Pages` สำเร็จ
5. URL จะอยู่ที่ `https://USERNAME.github.io/REPOSITORY/`

## ข้อจำกัด
- ข้อมูลช่องเก็บใน localStorage เฉพาะเบราว์เซอร์/อุปกรณ์ ไม่ซิงก์ข้ามเครื่อง ควรส่งออก M3U เพื่อสำรอง
- นำเข้า M3U แบบไฟล์เท่านั้น ไม่ดึง playlist URL ข้ามโดเมนเพื่อหลีกเลี่ยงปัญหา CORS
- รองรับ HTTP(S) stream ที่เบราว์เซอร์เล่นได้ โดยเฉพาะ HLS (.m3u8) แต่ไม่รองรับ DRM และบาง URL อาจติด CORS/geo-block
- หน้า GitHub Pages เป็น HTTPS ดังนั้นสตรีม HTTP อาจถูกเบราว์เซอร์บล็อก (mixed content)
- PWA ใช้ service worker ขั้นพื้นฐานและต้องออนไลน์เพื่อรับชมสตรีมสด
- ไม่มีระบบยืนยันตัวตนหรือฐานข้อมูลส่วนกลาง
- ใช้เฉพาะสตรีมที่มีสิทธิใช้งาน

## V0.2 — Adaptive UI
- เลือกโหมดหน้าจอจากเมนูด้านบน: อัตโนมัติสำหรับมือถือ/แท็บเล็ต/PC หรือ Smart TV
- Smart TV เริ่มด้วยรายการช่องซ้อนบนเครื่องเล่น; ปุ่มด้านบนสลับเป็นรายการด้านข้าง
- ใน TV Mode กดปุ่มทิศทางเพื่อเปิดและเลื่อนเมนู, Enter เพื่อเลือก, Escape/Backspace เพื่อปิด
- บนแท็บเล็ตแนวนอนแสดงรายการช่องด้านข้างเมื่อความกว้างเหมาะสม
- รายการช่องยังเก็บเฉพาะใน localStorage ของแต่ละเบราว์เซอร์
- การเล่นจริงขึ้นอยู่กับ HLS/CORS/DRM และการรองรับของเบราว์เซอร์ทีวี
- ยังไม่ได้ยืนยัน build ผ่าน npm ในสภาพแวดล้อมนี้ (การติดตั้งแพ็กเกจหมดเวลา)

## V0.4

ดู VALIDATION-REPORT.md สำหรับรายการตั้งต้น เครดิต ขอบเขตการตรวจ และวิธีเผยแพร่ GitHub Pages

ใช้ `npm ci`, `npm test`, `npm run build` สำหรับตรวจชุดส่งมอบ และใช้ `npm run dev` เพื่อเปิดแอปสำหรับพัฒนา แอปจะโหลด Playlist ตั้งต้นจาก public/ โดยอัตโนมัติ

`python audit/verify.py` ใช้ curl และ ffprobe ตรวจแหล่งที่ผ่านการทบทวนใน audit/sources.json แล้วสร้าง Playlist และรายงานใหม่ ค่า STREAM_ORIGIN ใช้กำหนด Origin ของเว็บปลายทาง ให้ตรวจ diff ของรายการที่เปลี่ยนก่อนนำขึ้นเผยแพร่
